# 🛡️ Sanraksha - Women Safety App

Sanraksha is a comprehensive women safety mobile application built to empower and protect women in times of emergency. With a single tap, the app activates multiple safety features to ensure help reaches the user quickly and efficiently.

## 🚀 Features

### 🔴 1. SOS Emergency Button
- On pressing the **SOS button**, an alert message is immediately sent to your registered emergency contacts.
- The message includes your **live location** to ensure you can be located quickly.

### 🔊 2. Siren Activation
- Along with sending the SOS message, a **loud siren** is triggered to attract attention and deter any potential threat.

### 📍 3. Live Location Tracking
- Your current location is continuously tracked during an emergency.
- This live location is sent via SMS to the selected emergency contacts for real-time tracking.

### 🗺️ 4. Safe Location Finder
- Find **safe places near you** like police stations, hospitals, or public spaces.
- Makes it easier to navigate to a safer zone when feeling unsafe.

### 📰 5. Women Safety Articles
- A dedicated section where users can **read or contribute articles** on women safety.
- Learn safety tips, self-defense strategies, and stay informed.
